🐛 COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

Issue: MongoDB Connection Failed
Solution: Start MongoDB service or configure MongoDB Atlas in .env

Issue: CORS Error in Browser
Solution: Restart backend after any .env changes

Issue: Can't Login
Solution: Verify user exists, check credentials

Issue: 404 Not Found
Solution: Verify API endpoint URL is correct

Issue: Frontend Blank Page
Solution: Check console for errors, verify port 8000 is available

See SETUP_GUIDE.md for detailed troubleshooting
