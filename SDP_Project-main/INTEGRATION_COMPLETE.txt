## 🚀 How to Start (3 Steps)

### Step 1: Start Backend
```powershell
cd backend
npm install    # First time only
npm run dev
```

**Expected:** `ParadeOps Backend Server running on port 5000`

### Step 2: Start Frontend
```powershell
cd frontend
python -m http.server 8000
```

**Expected:** `Serving HTTP on 0.0.0.0 port 8000`

### Step 3: Open Browser
```
http://localhost:8000/login.html
```

**You should see:** ParadeOps login page with military theme

## 🚨 Common Issues & Solutions

### MongoDB Connection Failed
**Solution:** Check MongoDB is running
```powershell
mongod --dbpath "C:\data\db"
```

### CORS Error in Browser
**Solution:** Restart backend after .env changes
```powershell
Ctrl+C (in backend terminal)
npm run dev
```

### Can't Connect to Backend
**Solution:** Verify backend is running
```powershell
curl http://localhost:5000/health
```

### Login Fails
**Solution:** Check user exists in database
- Register new user first
- Verify credentials before login
- Check browser console for errors
