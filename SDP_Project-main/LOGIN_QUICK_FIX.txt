## 🔍 DETAILED TROUBLESHOOTING

### If Registration Fails

**Error: "Connection error"**
- Backend not running
- Fix: Backend terminal shows it should be running
- Try: Restart backend with `npm run dev`

**Error: "User already exists"**
- Service number already registered
- Fix: Use a different service number (e.g., SOLDIER-002)

### If Login Fails

**Error: "Invalid credentials"**
- User doesn't exist OR wrong password
- Fix: Make sure you registered and use password: `1234`

**Error: "Connection error" on login**
- Frontend can't reach backend
- Possible causes:
  1. Backend not actually running
  2. Port 5000 blocked/unavailable
  3. CORS issue
- Fix: 
  - Stop backend (Ctrl+C)
  - Restart: `npm run dev`
  - Check for error messages

**Error: "undefined" or blank error**
- Backend error not caught properly
- Fix: Check backend terminal for error logs

## 🆘 IF STILL NOT WORKING

### Check 1: Backend Actually Running?
In **new** terminal:
```powershell
Test-NetConnection localhost -Port 5000
```

Should show: `TcpTestSucceeded : True`

### Check 2: Can Browser Reach Backend?
Open browser console (F12) and run:
```javascript
fetch('http://localhost:5000/health')
  .then(r => r.json())
  .then(d => console.log(d))
  .catch(e => console.log('ERROR:', e))
```

Should print: `{status: "ok", timestamp: "..."}`

### Check 3: Is Database Working?
Backend terminal should show:
```
✓ MongoDB connected successfully
```

If not, MongoDB might not be running.

### Check 4: Frontend Connected?
Browser Network tab (F12 → Network) should show:
```
POST /api/auth/register → Status 201 or 200
POST /api/auth/login → Status 200
```
