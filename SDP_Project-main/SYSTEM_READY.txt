📋 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

If you see "Connection error":

1. Check backend is running:
   - Terminal should show "Server ready for requests..."
   
2. Check frontend is running:
   - Terminal should show "Frontend Server running..."

3. Try in different browser:
   - Sometimes cache causes issues
   - Use Ctrl+F5 to hard refresh

4. Check if user exists in MongoDB:
   - Make sure service number and password are correct
